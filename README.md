# 📊 Marketing Campaign Effectiveness Dashboard

A data analytics project built using **Microsoft Power BI** to analyze marketing campaign performance, evaluate return on investment (ROI), and identify opportunities to improve campaign effectiveness.

## 📌 Project Overview

Marketing campaigns generate large amounts of data, but businesses need clear insights to understand which campaigns perform best. This project transforms marketing data into an interactive dashboard that helps users monitor revenue, spending, conversions, and campaign performance.

The dashboard provides a consolidated view of key performance indicators (KPIs), regional performance, channel effectiveness, and campaign-level metrics.

## 🎯 Project Objectives

- Analyze marketing campaign performance using data visualization.
- Track revenue, impressions, spending, and conversions.
- Compare campaign performance across marketing channels and regions.
- Evaluate campaign ROI and conversion rates.
- Support data-driven marketing decisions through interactive reports.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Calculated measures and KPI analysis, where applicable
- **Microsoft Excel** — Dataset storage and preparation

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Revenue
- Total Impressions
- Total Marketing Spend
- Total Conversions

### 2. Revenue Analysis
Visualizes revenue performance across different regions and marketing channels.

### 3. Campaign Performance Analysis
Compares campaign revenue, budget spending, and ROI to help evaluate campaign effectiveness.

### 4. Channel Performance
Analyzes conversions across marketing channels to identify which channels contribute most to campaign results.

### 5. Campaign Details Table
Provides campaign-level information, including:
- Campaign Name
- Conversions
- Budget Spend
- ROI
- Conversion Rate

### 6. Interactive Filtering
Region and launch-date slicers can be used to filter the report when included in the dashboard.

## 📊 Key Metrics

| Metric | Description |
|---|---|
| Revenue | Total revenue generated by campaigns |
| Impressions | Total times campaign content was displayed |
| Marketing Spend | Total campaign expenditure |
| Conversions | Number of recorded conversion events |
| CTR | Click-through rate |
| Conversion Rate | Percentage of relevant interactions resulting in conversions |
| ROI | Return on investment percentage |

*Metric definitions and formulas should follow the definitions used in the dataset.*

## 🗂️ Dataset Description

The dataset contains campaign-level marketing information, including fields such as:

- `Campaign_ID`
- `Campaign_Name`
- `Campaign_Type`
- `Channel`
- `Region`
- `Launch_Date`
- `Budget_Spend_USD`
- `Impressions`
- `Clicks`
- `Conversions`
- `CTR_Percent`
- `Conversion_Rate_Percent`
- `Revenue_USD`
- `ROI_Percent`

The dashboard uses these fields to analyze marketing performance from multiple perspectives.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` dashboard file in Power BI Desktop.
4. If prompted, update the dataset source path.
5. Refresh the data if required.
6. Explore the dashboard visuals and available filters.
